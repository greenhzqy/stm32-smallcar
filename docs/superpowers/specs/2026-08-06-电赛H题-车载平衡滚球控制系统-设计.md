## 一、赛题要求摘要

H题要求在循迹小车基础上加装**平衡滚球装置**：

- **赛道**：白色底板 + 黑色循迹线（线宽1.8cm），AB/CD 直道 1.5m，BC/DA 半圆半径 0.5m
- **摆杆**：PPR水管，长 25cm，外径 2cm，壁厚 0.34cm，中点处转轴
- **钢珠**：直径约 1cm，在管内滚动
- **平台高度**：h = 5cm（摆杆离地高度）
- **车体限制**：≤ 35cm 长，≤ 25cm 宽

### 得分项（总分100）

| 题目 | 要求 | 分值 |
|------|------|------|
| 1 | 基本安装 + 显示 | 3 |
| 2 | 巡线一圈，≤20s，停在A点，偏差≤2cm | 16 |
| 3 | 静止时控球：中心 → -5cm，稳定时间≤5s，偏差≤1cm | 13 |
| 4 | A→B 段行驶(≤8s)，球稳定在中心，偏差≤1cm | 20 |
| 5 | 巡线一圈(≤30s)，球稳定在中心，偏差≤1cm | 20 |
| 6 | 巡线一圈，球稳定在指令位置，偏差≤1cm | 20 |
| 设计报告 | — | 20 |

### 关键约束

- 只能用红外传感器模块（不能用摄像头/视觉）
- 显示装置 ≥ 2英寸，必须装在车体上
- 行驶中车轮投影不得完全超出轨迹线

### 2.2 引脚分配

```
STM32F103C8T6 (LQFP48)

已有：
  PA0  ← TCRT5000 (R2)
  PA1  ← TCRT5000 (L2)
  PA2  ← TCRT5000 (L1)
  PA3  ← TCRT5000 (R1)
  PA6  ← TIM3_CH1  左电机 PWM
  PA7  ← TIM3_CH2  右电机 PWM
  PB0  → 左电机 AIN1
  PB1  → 左电机 AIN2
  PB8  ↔ OLED SCL (软件 I2C)
  PB9  ↔ OLED SDA (软件 I2C)
  PB10 → 右电机 BIN1
  PB11 → 右电机 BIN2

新增：
  PB6  ↔ I2C1_SCL   VL53L0X + MPU6050 (硬件 I2C)
  PB7  ↔ I2C1_SDA   VL53L0X + MPU6050
  PA8  → TIM1_CH1   舵机 PWM
  PB12 ← 按键输入    模式切换

I2C 设备地址：
  VL53L0X: 0x29
  MPU6050: 0x68
  → 同一总线，地址不冲突
```

### 2.3 供电方案

```
4×AA 南孚碱性电池 (6.4V 满电 ~ 4.8V 可用下限)
    │
    ├──→ TB6612 VM 引脚          (直接供电)
    │
    ├──→ 舵机 VCC                (直接供电，舵机支持 4.8V~7.2V)
    │
    └──→ AMS1117-3.3V ──→ 3.3V ──→ STM32 + OLED + VL53L0X + MPU6050 + TCRT5000
               │
        输入端并 470μF 电解电容 (防电机启动时电压瞬降)
```

> 比赛时使用全新电池。南孚满电 1.6V/节 × 4 = 6.4V，一次比赛运行时间约几分钟，电池压降在可接受范围。

### 2.4 机械结构

```
                      前(行驶方向)
                      ↑
         ┌─────────────────────────┐
         │    [TCRT5000×4]         │  ← 底盘前沿下方，一字排开
         │                         │
         │   ┌───┐         ┌───┐   │
         │   │左轮│         │右轮│   │
         │   └───┘         └───┘   │
         │                         │
         │       ═══PPR水管═══     │  ← 管长 25cm，装在转轴上(中点)
         │       │← 钢珠滚 →│     │      平台高度 h = 5cm
         │       ════════════     │
         │       ↑       ↑        │
         │     转轴    VL53L0X    │  ← 传感器装在管口，激光向内打
         │              ↑         │
         │           连杆→舵机     │  ← 舵机通过连杆控制管子倾角
         │                         │
         └─────────────────────────┘
                      后
```

- **转轴位置**：管子中点（距两端各 12.5cm），用 3D 打印支架 + 轴承/铰链
- **舵机连接**：舵机臂 → M2 拉杆 → 管子一端，舵机旋转 = 管子绕中点倾斜
- **VL53L0X 安装**：3D 打印圆环支架卡在管口外侧，传感器窗口对准管内
- **钢珠**：直径 ~1cm，活动范围为中心±5cm（约 7.5~17.5cm 以传感器为参考零点）

## 三、软件架构

### 3.1 新增文件结构

```
Core/
├── Inc/
│   ├── ball.h          ← VL53L0X 驱动 + 中值滤波
│   ├── pendulum.h      ← 舵机控制 + 串级PID内环
│   ├── imu.h           ← MPU6050 驱动 + 姿态解算
│   ├── chassis.h       ← 循迹+电机（封装现有 motor.c/track.c）
│   └── task_manager.h  ← 6模式任务调度
├── Src/
│   ├── ball.c
│   ├── pendulum.c
│   ├── imu.c
│   ├── chassis.c
│   └── task_manager.c
```

### 3.2 模块分层

```
┌─────────────────────────────────┐
│        task_manager             │  ← 顶层：赛题模式选择与切换
│  "执行第几题？"                  │
├─────────────────────────────────┤
│  chassis │ pendulum │  ball    │  ← 中间层：子系统控制
│  巡线+   │ 摆杆舵机 │ TOF测距  │
│  差速    │ +串级PID  │ +滤波   │
├─────────────────────────────────┤
│ motor  track  I2C  TIM1  MPU6050│ ← 底层：硬件驱动
└─────────────────────────────────┘
```

- 层层调用，不跨层

### 3.3 核心控制流程

```
传感器输入：
  TCRT5000×4 ──→ 线偏差 ──→ 差速PID ──→ 左右电机
  VL53L0X    ──→ 球位置 ──→ 外环PID ──→ 目标倾角
  MPU6050    ──→ 倾角    ──→ 内环PID ──→ 舵机PWM
  MPU6050    ──→ 偏航角  ──→ 一圈判定 / 转弯检测

前馈补偿（预留接口）：
  MPU6050    ──→ 检测到转弯 ──→ 摆杆内倾偏置（抵消离心力）
  MPU6050    ──→ 检测到加减速 ──→ 摆杆前后偏置（抵消惯性）
```

### 3.4 串级 PID 参数预留

```
外层PID (球位置 → 目标倾角):
  Kp_outer, Ki_outer, Kd_outer
  频率: 50Hz (20ms周期)
  输入: ball_target - ball_actual
  输出: target_tilt_angle

内层PID (倾角 → 舵机PWM):
  Kp_inner, Ki_inner, Kd_inner
  频率: 200Hz (5ms周期)
  输入: target_tilt_angle - imu_actual_tilt
  输出: servo_pwm_value
```

### 3.5 控制频率分配

| 任务 | 频率 | 周期 |
|------|------|------|
| 摆杆内环 PID | 200Hz | 5ms |
| 巡线 PID | 200Hz | 5ms |
| 球位置外环 PID | 50Hz | 20ms |
| MPU6050 读取 | 200Hz | 5ms |
| OLED 刷新 | 2Hz | 500ms |
| 一圈判定检查 | 200Hz | 5ms |

### 3.6 TOF 读数滤波

- **中值滤波**：缓存5个读数，排序取中值（过滤尖峰跳变）
- **限幅滤波**：两次有效读数差 > 2cm 则丢弃（钢珠不可能瞬间位移太大）

### 3.7 任务状态机

```
上电 → OLED显示 "Mode: X"
  │
  ├─ 按键短按 → Mode 切换 (1→2→3→4→5→6)
  │
  └─ 按键长按 (≥2秒) → 3秒倒计时 → 执行当前Mode
                              │
                    ┌─────────┴──────────┐
                    ↓                    ↓
              Mode 1~6 执行      按键短按 → 紧急停车
                    │
                    ↓
              完成 → 显示结果 → 等待复位
```

| 模式 | 赛题 | 动作 |
|------|------|------|
| Mode 1 | 第2题 | 巡线一圈 → 停A点 |
| Mode 2 | 第3题 | 静止控球：中心 → -5cm |
| Mode 3 | 第4题 | 巡线 A→B + 球稳定中心 |
| Mode 4 | 第5题 | 巡线一圈 + 球稳定中心 |
| Mode 5 | 第6题 | 巡线一圈 + 球稳定在指令位置 |
| Mode 6 | 创意 | 预留 |

### 3.8 一圈判定逻辑

```
MPU6050 Z轴角速度 (每5ms读取一次)
          ↓
   偏航角 += ωz × 0.005s   (梯形积分)
          ↓
   偏航角 ≥ 360° → 一圈完成
          ↓
   继续前进至 A点停止线
          ↓
   TCRT5000 检测到停止标志 → 刹车
```

- 陀螺仪判"跑够了"，停线判"停对了"——双重确认

### 3.9 TOF 滤波策略

- 中值滤波（窗口=5）：过滤偶然跳变
- 限幅滤波（Δ≤2cm）：球不可能瞬移

## 四、开发阶段规划

### 阶段 1：硬件搭建（不改代码）

- 搭建摆杆机构 + 安装舵机 + 安装 VL53L0X
- 连接 MPU6050、VL53L0X 到 I2C 总线
- 连接舵机到 PA8
- 焊接按键到 PB12

### 阶段 2：底层驱动验证

- MPU6050 驱动：I2C 读取加速度+角速度，OLED 显示验证
- VL53L0X 驱动：I2C 读取距离值，OLED 显示验证
- 舵机驱动：TIM1 PWM 输出，测试摆杆在不同角度
- 按键检测：中断/轮询，模式切换逻辑

### 阶段 3：控制算法调参

- 内环摆杆 PID：先用手拨动摆杆看回正效果
- 外环球位置 PID：静止时控球到中心
- 巡线+控球合并：慢速行驶联合调试
- 前馈补偿：加入转弯预判

### 阶段 4：赛题模式整合

- task_manager 状态机
- 各模式独立调参
- 全流程自动测试

### 阶段 5：PCB 打样

- 原理图

## 五、已知风险与对策

| 风险 | 概率 | 对策 |
|------|------|------|
| VL53L0X 对钢珠镜面反光测不稳 | 中 | 中值+限幅滤波；备选 TCRT5000 密集阵列 |
| AMS1117 输入电压不够导致 MCU 复位 | 低 | 470μF 电容缓冲 + 比赛用新电池 |
| 舵机扭矩不够驱动摆杆 | 低 | MG996R 金属齿，10kg·cm，25cm管+钢珠完全够 |
| MPU6050 偏航角漂移 | 高 | 一圈判定仅需 360° 粗略值，漂移在 30 秒内可接受 |
| 过弯时球飞出可控范围 | 中 | 弯道降速 + MPU6050 前馈补偿 |
| PPR 管壁干扰 TOF 测距 | 低 | PPR 是红外不透明材质，不干扰 940nm 激光 |
