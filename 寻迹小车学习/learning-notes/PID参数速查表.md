# PID 参数速查表

> 当前值更新时间：[[2026-08-06]]

## 当前参数

| 参数 | 值 | 作用 |
|------|:--:|------|
| `Kp` | 10.0 | [[PID三个参数\|主力纠偏]] |
| `Ki` | 0.15 | [[PID三个参数\|修正物理不对称]] |
| `Kd` | 8.0 | [[PID三个参数\|抑制震荡]] |
| 积分上限 | ±3 | [[积分饱和\|防积分饱和]] |
| 输出上限 | ±400 | 防差速过大 |
| 控制周期 | 5ms | 200Hz 固定步长 |

## 三层速度

| 路况 | base_speed | 触发条件 |
|------|:--:|------|
| 直线 | **450** | `|error| ≤ 1.5` |
| 缓弯 | **350** | `1.5 < |error| ≤ 3` |
| 急弯/丢线 | **250** | `|error| > 3` |

详见 [[两层控制-差速与整体速度]]

## 调参方向

| 症状 | 调法 |
|------|------|
| 直线左右摆 | 减 Kp 或 加 Kd |
| 过弯冲出去 | 加 Kp |
| 直线走不直（总偏一边） | 加 Ki |
| 反应迟钝、拐不过弯 | 加 Kp 或 减 Kd |
| 电机高频抖动 | 减 Kd 或 检查[[传感器去抖\|去抖]] |
| 弯道不稳 | 降 base_speed 急弯档 |
