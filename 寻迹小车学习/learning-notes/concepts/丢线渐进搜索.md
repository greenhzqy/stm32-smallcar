# 丢线渐进搜索

## 一句话

丢线后不要用同一个力度傻转——越久找不到线，转得越猛。

## 问题

旧代码丢线时：

```c
error = last_error;  // 永远用同一个力度
```

如果这个力度不够大（转弯半径比线的弯度大），就**永远找不回线**。

## 直觉

在黑暗中找手电筒：
- 刚丢 → 小范围找（应该就在附近）
- 丢了一阵 → 扩大搜索范围
- 丢了很久 → 最大力度搜索

## 实现

```c
static uint16_t loss_count = 0;  // 丢线计数器，每5ms+1

if(全白) {
    loss_count++;

    // 确定方向：线最后在哪边就往哪边找
    float search_dir = (last_error > 0) ? 1.0f : -1.0f;

    // 力度渐增：起步3，每5ms加0.5，上限8
    float power = 3.0f + loss_count * 0.5f;
    if(power > 8.0f) power = 8.0f;

    error = search_dir * power;
} else {
    loss_count = 0;  // 找到线马上重置
}
```

| 丢线时长 | search_power | 行为 |
|------|:--:|------|
| 5ms | 3.5 | 小幅度找 |
| 25ms | 5.5 | 中等幅度 |
| 50ms | 8.0（上限） | 全力搜索 |

## 配合措施

丢线时还要做两件事：

1. **冻结积分**：丢线时 `error` 被人为放大，如果继续累加积分会导致 [[积分饱和]]，找到线后反而超调
2. **降速**：丢线搜索时 `abs_error > 3`，[[两层控制-差速与整体速度|自动降速]]到 250，慢速搜索更安全
