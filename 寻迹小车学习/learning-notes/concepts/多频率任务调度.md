# 多频率任务调度

> 在一个 while(1) 循环里跑不同频率的任务

## 一、问题

```c
// ❌ 错误做法：多个 Delay 堆叠
while(1) {
    任务A();  HAL_Delay(5);   // A 每 5ms
    任务B();  HAL_Delay(20);  // B 每 20ms
    任务C();  HAL_Delay(500); // C 每 500ms
}
// 总延迟 = 5+20+500 = 525ms，完全废了
```

---

## 二、解法：计数法

```c
while(1) {
    // === 每圈都跑 (200Hz) ===
    任务A();  // 巡线 PID + 内环 PID + MPU6050

    // === 每 4 圈跑一次 (50Hz) ===
    static uint8_t cnt_b = 0;
    cnt_b++;
    if(cnt_b >= 4) {
        cnt_b = 0;
        任务B();  // 外环 PID
    }

    // === 每 N 圈跑一次 (2Hz) ===
    static uint32_t timer_c = 0;
    if(HAL_GetTick() - timer_c > 500) {
        timer_c = HAL_GetTick();
        任务C();  // OLED 刷新
    }

    HAL_Delay(5);  // 统一一个 Delay
}
```

---

## 三、核心理念

**快的每圈跑，慢的数圈跑。**

不是"每个任务轮着做"——是**每圈都检查一遍，谁的计数器/时间戳到了谁干活。**

---

## 四、当前项目应用

OLED 刷新用的就是时间戳法：

```c
static uint32_t oled_timer = 0;
if(HAL_GetTick() - oled_timer > 500) {
    oled_timer = HAL_GetTick();
    // 刷 OLED
}
```

H 题的 50Hz 外环 PID 用计数法（`cnt++ % 4 == 0`），原理完全一样。

---

## 五、为什么不直接用多个定时器中断

可以，但复杂。计数法足够用了——5ms 控制周期，4 次计数判定就 20ms，精度完全够。
