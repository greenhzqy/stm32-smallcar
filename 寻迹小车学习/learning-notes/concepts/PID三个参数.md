# PID 三个参数

## 一句话

Kp 管现在、Ki 管过去、Kd 管未来。

## 三个参数的分工

| 参数 | 人话 | 管什么 | 比喻 |
|------|------|------|------|
| **Kp** | "你偏了，马上掰回来" | **即时纠偏** | 眼睛看路 |
| **Ki** | "你老往左偏，我帮你补偿" | **系统性物理偏差** | 发现方向盘本身歪了 |
| **Kd** | "你冲太快了，提前收油" | **震荡、超调、抖动** | 感觉车身要甩尾 |

## Kp — 比例项

```c
Kp × error   // error = 当前位置偏离中心多远
```

偏多少就打多少方向盘。反应快，但偏一消失就不干活了。

## Ki — 积分项

```c
Ki × sum_error   // sum_error = 历史上所有偏差的累加
```

像一个水桶，每次偏左就加水，偏右就舀水。桶里的水量 = "你整体上偏了多少"。

**Ki 解决的是物理世界的不完美：**
- 左电机比右边弱一点
- 电池给两个电机的电压不等
- 轮子直径差 0.1mm
- 车架重心偏一侧

这些是 Kp 一个人修不掉的——Kp 纠正完，根源还在，下次还会偏。Ki 慢慢积累一个持久补偿力。

> ⚠️ **常见误解：** 以为 Ki 是用来抑制抖动的。错！
> **Kd 才是抑制抖动的。** Ki 是针对"长时间存在的系统性偏差"。

## Kd — 微分项

```c
Kd × (error - last_error)   // 偏差的变化速度
```

"你现在偏了"不可怕，"你正在加速偏离"才可怕。Kd 在偏离加速时提前踩刹车。

## 调参口诀

| 症状 | 调法 |
|------|------|
| 直线左右摆 | 减 Kp 或加 Kd |
| 过弯冲出去 | 加 Kp |
| 直线走不直（偏一边） | 加 Ki |
| 反应迟钝 | 加 Kp 或减 Kd |
| 电机抖动 | 减 Kd 或检查[[传感器去抖]] |
