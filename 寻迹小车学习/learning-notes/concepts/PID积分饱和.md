# PID 积分饱和

> 对 [[PID三个参数]] 中 Ki 和积分项的深入讨论

## 一、积分项在干什么

```c
sum_error += error;       // 每次循环累加偏差
output = Kp*error + Ki*sum_error + Kd*diff_error;
```

`sum_error` 就像**记账本**——"偏了多久了？偏得越久，我纠正得越狠。"

积分项的设计初衷是修正**永久性偏差**（如左轮天生比右轮慢）。

---

## 二、积分饱和问题

### 场景：大右弯持续 3 秒

```
error 一直是 +1.5
3 秒 / 5ms = 600 次循环
sum_error = 600 × 1.5 = 900  ← 爆炸了

弯道结束时: output = Kp×0.5 + Ki×900
                    = 5 + 135
                    = 140  ← 积分项占 96%
```

车出弯后，积分项的惯性会让车猛烈冲过中线。

### 场景：丢线 2 秒

```
丢线时 error 被塞入很大的值（如 8.0）
2 秒 / 5ms = 400 次
sum_error = 400 × 8 = 3200  ← 更炸
```

线找到后积分项的残余力量会让车"嗖"地冲出去。

---

## 三、当前代码的两层保护

```c
// 第一层：丢线时冻结积分（不瞎记）
if(!line_lost) {
    sum_error += error;
}

// 第二层：正常巡线但有上限（不记太多）
if(sum_error > 3)  sum_error = 3;
if(sum_error < -3) sum_error = -3;
```

| 保护层 | 防什么 |
|--------|--------|
| 丢线冻结 | 在不知道线在哪的时候别瞎记 |
| 限幅 ±3 | 弯道太久时，不让积分学错东西 |

---

## 四、关键认识

积分**不是在"学习"或"自适应"**——它只是一个会累积的加法器。Ki 从头到尾都是手调的静态值（`0.15f`），运行时没有任何代码在改它。

**弯道的偏差是临时的、不该被记住的，但积分不加区分什么都记。限幅就是给积分设忘性上限。**

---

## 五、类比：水桶

```
sum_error = 水桶
每次 error = 倒入的水
限幅 = 桶盖

丢线冻结 = 发现水源有问题，暂停倒水
限幅 = 桶满了就倒不进去了 → 防止溢出
```
