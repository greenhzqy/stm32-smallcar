# 传感器去抖

## 一句话

连读多次取多数，过滤黑白边界的信号抖动。

## 问题

红外传感器（TCRT5000）在黑白交界处输出疯狂跳变：`1→0→1→0→1→0…`，每秒几百次。

如果直接把抖动值喂给 [[PID三个参数|PID]]，电机每 5ms 收到不同指令，表现为**时快时慢、左右摇摆**。

## 直觉

在嘈杂的房间听人说话——问 3 遍，3 遍答案一样才信。偶尔听错一次不算数。

## 实现

```c
// 连读 3 次，取多数（3取2）
static uint8_t debounce_read(GPIO_TypeDef *port, uint16_t pin) {
    uint8_t r1, r2, r3;
    r1 = HAL_GPIO_ReadPin(port, pin);
    tiny_delay();  // 等电平稳定，~1μs
    r2 = HAL_GPIO_ReadPin(port, pin);
    tiny_delay();
    r3 = HAL_GPIO_ReadPin(port, pin);
    return (r1 + r2 + r3 >= 2) ? 1 : 0;  // 多数表决
}
```

## ⚠️ 常见误解

去抖 ≠ 加延时。区别：

| | 去抖 | 加延时 |
|------|------|------|
| 做法 | 同一时刻连读多次确认 | 拉长两次控制的间隔 |
| 效果 | 过滤噪声 | 只是降低采样率，噪声还在 |
| 方向 | "横着"的（一批读多次） | "竖着"的（拉长批次间距） |
