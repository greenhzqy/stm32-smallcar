# PID 微分项（D 项）

> 对 [[PID三个参数]] 中 Kd 和 diff_error 的深入讨论

## 一、微分项的计算

```c
float diff_error = error - last_error;   // 当前误差 - 上次误差
float output = Kp*error + Ki*sum_error + Kd*diff_error;
// ...
last_error = error;   // 存起来，下次循环用
```

**就两行代码，只做了一次减法。**

---

## 二、diff_error 的物理意义

| diff_error | 含义 | 场景 |
|------------|------|------|
| **正** | 误差在变大 | 入弯（偏离越来越严重）|
| **零** | 误差不变 | 直道巡航或弯道中稳定 |
| **负** | 误差在变小 | 出弯（正在回到线上）|

不是预测未来——是看趋势：**"上一刻和这一刻比，情况变好了还是变差了？"**

---

## 三、手动推算

### 入弯
```
第1次: error=0.5  → diff=0.5-0  =+0.5 ✅ 正
第2次: error=1.5  → diff=1.5-0.5=+1.0 ✅ 正，偏差在变大
第3次: error=2.5  → diff=2.5-1.5=+1.0 ✅ 正
```

### 出弯
```
第10次: error=3.0  → diff=3.0-2.8=+0.2
第11次: error=2.0  → diff=2.0-3.0=-1.0 ✅ 负！偏差在变小，出弯了
第12次: error=1.0  → diff=1.0-2.0=-1.0 ✅ 负
```

---

## 四、微分项对电机的作用

```c
output = Kp*error + Ki*sum_error + Kd*diff_error;
// Kd = 8.0
```

入弯时 diff_error = +1.0：
```
output += 8.0 × 1.0 = +8 → 差速更猛 → 对抗入弯
```

出弯时 diff_error = -1.0：
```
output += 8.0 × (-1.0) = -8 → 差速减弱 → 防止冲过头
```

**微分项是"刹车"——阻止 error 变化太快。入弯刹住别冲，出弯刹住别过。**

---

## 五、数学本质

| 数学 | PID 对应 | 含义 |
|------|----------|------|
| f(x) | error（P项） | **现在**在哪 |
| f'(x) | diff_error（D项） | 往**哪个方向**变 |
| f''(x) | PID 不用 | 变化本身在加速还是减速 |

**微分项是一阶导数，不是二阶。**

---

## 六、可以用于智能降速

diff_error 能比 abs_error 更早判断湾道趋势：

```
abs_error 大 + diff_error 正 → 正在入弯 → 提前减速
abs_error 大 + diff_error≈0 → 弯道中稳定巡航
abs_error 小 + diff_error 负 → 正在出弯 → 加速
```

比 `if(abs_error > 3.0f) base_speed=250` 这样的阈值判断更快。
