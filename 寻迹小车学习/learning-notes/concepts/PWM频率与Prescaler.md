# PWM 频率与 Prescaler

## 一句话

Prescaler 决定了 PWM 的频率，频率太低电机就会没力气。

## 直觉

PWM 就是快速开关电机。1kHz = 每秒开关 1000 次，18kHz = 每秒 18000 次。

电机是线圈——通电时电流慢慢上升，断电时慢慢下降。频率太低 → 电流还没升上去就被切断了 → 电机大部分时间"没吃饱" → **无力**。

```
低频（1kHz）：电流像锯齿，转矩不平稳
高频（18kHz）：电流几乎平直，转矩稳定有力
```

## 计算公式

```
定时器时钟 = 72MHz ÷ (Prescaler + 1)
PWM频率   = 定时器时钟 ÷ (Period + 1)

例：Prescaler=3, Period=999
  定时器时钟 = 72MHz ÷ 4 = 18MHz
  PWM频率   = 18MHz ÷ 1000 = 18kHz ✅
```

## 注意事项

Prescaler 改在 CubeMX 代码保护区之外。重新用 CubeMX 生成代码时会被覆盖。要在 CubeMX 的 TIM3 配置里手动改。
