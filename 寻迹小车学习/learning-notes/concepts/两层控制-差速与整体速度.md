# 两层控制：差速与整体速度

## 一句话

方向盘管转弯（差速），油门管快慢（整体速度）。两层独立工作。

## 第一层：差速控制（转弯）

```
左轮 = base_speed - output
右轮 = base_speed + output
```

`output` 来自 [[PID三个参数|PID 计算]]。output > 0 → 线在右边 → 右轮减速、左轮加速 → 车右转。

## 第二层：整体速度（弯道降速）

```c
float abs_error = |error|;  // 偏离中心多远

if(abs_error > 3.0f)       base_speed = 250;  // 线快丢了，慢！
else if(abs_error > 1.5f)  base_speed = 350;  // 缓弯，稳着点
else                       base_speed = 450;  // 直线，冲！
```

**不需要额外传感器。** 偏差 `error` 的大小就是弯道信号——偏差越大说明线偏得越远，弯就越急。

## 两层如何配合

| 路况 | base_speed | output | 效果 |
|------|:--:|:--:|------|
| 直线 | 450 | ≈0 | 全速直行 |
| 缓左弯 | 350 | -20 | 中速左转 |
| 急右弯 | 250 | +80 | 慢速急右转 |
| 丢线搜索 | 250 | 渐增 | 慢速大角度搜索 |

## 直觉

开车时：
- **右脚管油门**（base_speed）：直线踩到底，弯道松油门
- **双手管方向盘**（output）：偏了就掰，偏越多掰越多

两只脚、两套系统，各管各的。
