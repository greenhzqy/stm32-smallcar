# uint8_t 溢出

## 一句话

`uint8_t` 只能存 0~255，给它负数会溢出成 248 之类的大数。

## 案例

OLED 显示字符时，光标列坐标的计算：

```c
// ❌ 原有代码
OLED_SetCursor((Line - 1) * 2, (Column - 1) * 8);

// 当 Column = 0 时：
// (0 - 1) × 8 = -8
// 但 uint8_t 不能表示负数！
// -8 变成 248 → 光标跑到屏幕最右边 → 显示错位
```

## 原理

`uint8_t` = 无符号 8 位整数，范围 0~255。

对 uint8_t 做减法：
```
0 - 1 = 255
0 - 2 = 254
0 - 8 = 248
```

溢出了，绕着圈回来了。

## 修法

```c
// ✅ Column * 8：Column=0 → 0×8=0 → 第0列
OLED_SetCursor((Line - 1) * 2, Column * 8);
```
