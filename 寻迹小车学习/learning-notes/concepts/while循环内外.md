# while 循环内外

## 一句话

`while(1)` 里面的代码会反复执行，外面的只执行一次。

## 单片机程序结构

```c
int main(void) {
    初始化();      // ← 只执行一次
    初始化();
    初始化();

    while(1) {     // ← 从这里开始，无限循环
        读传感器(); // 每次都执行
        算PID();    // 每次都执行
        控电机();   // 每次都执行
    }
}
```

## 经典 bug

把传感器读取放在 while 外面：

```c
// ❌ 错误
uint8_t l1 = Track_L1();  // 开机时读一次，值永远不变
while(1) {
    if(l1 == 1) ...        // 用的永远是开机时的值
}
```

小车跑起来后传感器明明变了，但代码不知道——因为它只读了一次。
