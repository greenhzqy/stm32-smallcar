# 2026-08-05 首次调试

> 🚗 循迹小车 | STM32F103C8 + TCRT5000 + TB6612

---

## 🔧 调试：修了什么问题

### 症状

车能动但不巡线，电机无力，OLED 花屏错位。

### 根因分析

| 问题        | 根因                                 | 概念笔记 |
| --------- | ---------------------------------- | ---- |
| 电机无力      | [[PWM频率与Prescaler\|PWM频率太低（1kHz）]] | 🔗   |
| 不巡线       | [[while循环内外\|传感器在循环外只读了一次]]        | 🔗   |
| 右电机反转异常   | 变量名写错（left_speed → right_speed）    |      |
| OLED 花屏   | [[volatile与编译器优化\|编译器优化删掉了I2C延时]]  | 🔗   |
| OLED 字符错位 | [[uint8_t溢出\|Column=0时uint8_t溢出]]  | 🔗   |

### 改了什么

| 文件 | 改动 | 为什么 |
|------|------|------|
| `tim.c` | Prescaler 71→3 | [[PWM频率与Prescaler\|PWM 1kHz→18kHz]] |
| `main.c` | 传感器读取移入 while | [[while循环内外\|每轮重新读取]] |
| `motor.c` | `left_speed`→`right_speed` | 修右电机分支变量名 |
| `OLED.c` | 延时加 `volatile` | [[volatile与编译器优化\|防编译器删延时]] |
| `OLED.c` | `Column*8` 替代 `(Column-1)*8` | [[uint8_t溢出\|修溢出]] |
