## 📚 学到的东西

### 今天搞懂的概念

- [[传感器去抖]] — ⚠️ 去抖≠加延时，是同一时刻连读多次确认
- [[PID三个参数]] — ⚠️ Ki 不管抖动！Kd 才管抖动。Ki 管物理不对称
- [[积分饱和]] — 水桶太大，100ms就满，积分失去意义
- [[两层控制-差速与整体速度]] — 方向盘(差速) vs 油门(整体速度)
- [[丢线渐进搜索]] — 丢得越久转得越猛
- [[OLED软件I2C阻塞]] — 定时器能解决计时，解决不了传输速度

### 澄清的误解

| 我以为 | 实际是 |
|------|------|
| 去抖 = 加延时等待 | 去抖 = 连读多次取多数 |
| Ki 管抖动抑制 | Kd 才管抖动，Ki 管系统偏差 |
| 弯道判断需要新传感器 | error 的大小就是弯道信号 |
| 定时器能解决 OLED 卡顿 | 只能解决计时，不能解决传输速度 |

### 今日搞懂的概念

- [[I2C通信协议]] — SCL/SDA 两根线，地址点名机制，软件 I2C vs 硬件 I2C
- [[PWM深入理解]] — PSC/ARR/CCR 三大寄存器，电机 vs 舵机 PWM 的本质区别
- [[PID积分饱和]] — 积分项会"学错"临时偏差，丢线冻结+限幅两层保护
- [[PID微分项]] — diff_error 是一阶导数看趋势，入弯正出弯负，微分是"刹车"
- [[串级PID]] — 内环(MPU6050看管子200Hz) + 外环(VL53L0X看球50Hz)，谁快谁跑高频
- [[多频率任务调度]] — 计���法代替多个 Delay，快的每圈跑慢的数圈跑

### 澄清的误解

| 我以为 | 实际是 |
|------|------|
| PWM 是把转动分成小块 | PWM 是靠电机惯性感受平均电压 |
| 舵机必须用 PWM 驱动 | 可以手动延时，但 PWM 解放 CPU |
| 积分项 = 自适应学习 | 积分只是累加加法器，Ki 全程手调不变 |
| 微分项 = 二阶导数 | 微分是一阶导数，只看变化方向 |
| 串级就是多个 PID 一起跑 | 内环高频盯管子(抗扰动)，外环低频盯球(定目标) |
| 不同频率任务要多个 Delay | 一个 Delay + 计数器分频即可 |
| 多任务调度 = 每个任务轮着做 | 检查时间戳/计数器，谁的周期到了谁干活 |

### 关键设计决策

- MPU6050 **装车身上**（Z轴不歪→偏航角准），不装管子上
- 管子角度 = 车身倾角 + 舵机命令角度
- 外环 50Hz 不能提 200Hz（球滚得慢，管子调太快会导致过冲）
- VL53L0X 对钢珠镜面反射 → 中值滤波 + 限幅滤波，不打磨钢珠
